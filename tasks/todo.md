# Aboutの画像を「触れる装置」に置き換え（2026-07-29）

トップページ About セクションの静止画（positron_beam.png）を、
研究室の核心である陽電子消滅法を体験できる対話型の装置に差し替え。

## 中身
- 結晶格子（六方最密風）を描画。4種の格子欠陥を配置：単空孔×2／2重空孔／転位（⊥記号付き）
- 陽電子 e⁺ がマウスに追従。近くの原子が押しのけられて格子がしなる
- 欠陥に入ると捕獲→らせん状に落ち込み→対消滅→**γ線2本が正反対に飛ぶ**（物理的に正しい180°）
- 寿命の数値は削除した araki_lab_diagram.png に載っていた**鉄の実測値**を採用：
  完全結晶107 / 転位150 / 単空孔177 / 2重空孔197 ps
- 欠陥に出会わないまま時間が経つと完全結晶中で対消滅（107 ps）
- クリック/タップで打ち込み（ピンクのビーム演出）。触らなくても自動で漂う
- 画面外・タブ非表示のときは停止。動きを減らす設定では静止画表示。読み上げ用の説明文も用意

## 実装上の要点
- 追従・原子の変位は **時間基準（1 - exp(-dt/τ)）** にしてリフレッシュレート非依存に
- dt を 0〜48ms に制限（タブ復帰などの時間跳躍対策）
- 原子は事前描画したスプライトを使い回し（毎コマ勾配生成を回避）
- 結合線は組み立て時に一度だけ算出

## 検証
- JSエラーなし。canvas 511x341 で正常描画
- 画素の色分布で確認：γ線=185〜342px、閃光=3,700〜10,300px、原子=約35,000px
- 欠陥ごとの寿命表示が正しい（単空孔177／2重空孔197／転位150）
- デスクトップ・スマホ幅とも表示崩れなし。スマホでは案内文を「タップ：打ち込む」に自動変更
- ※撮影の注意：headlessでは setTimeout 内の canvas 描画は画像に写らない（rAF経由なら写る）

## 残件
- images/positron_beam.png がこの差し替えで未使用に（削除するかは要判断）
