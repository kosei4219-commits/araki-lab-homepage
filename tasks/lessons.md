# 学びの記録（lessons）

## 2026-07-28 研究ページ刷新にて

5. **グリッド配置の子要素に「margin-inline: auto（中央寄せ）」を付けると、幅いっぱいに広がる性質が打ち消され、中身が空（子がすべて absolute）だと幅0に潰れる。**
   研究の流れ図の枠がスマホ幅で 2px に潰れた原因。
   → 中央寄せしたいグリッド子要素には `width: min(100%, 上限px)` のように幅を明示する。
   → 崩れの原因調査は、要素の実寸（getBoundingClientRect）を画面に書き出して撮影すると一発で特定できる。

## 2026-07-28 トップページ刷新にて

1. **デザイン案（AI生成モックアップ）の文章は信用しない。**
   デザイン画像内の文章には誤字・無関係な文が混ざる（例：「隣電子」→正しくは「陽電子」）。
   → 見た目だけをデザイン案から取り、文章は必ず現行サイト・一次情報から取る。

2. **画面撮影ツール（ヘッドレスブラウザ）は窓幅を約450pxより狭くできない。**
   `--window-size=390` を指定しても内部の表示幅は最小値のままで、画像だけが390pxに切り取られるため、
   「スマホ幅で右側がはみ出している」ように見える誤検出が起きる。
   → スマホ幅の検証は、ページを幅390pxの iframe に入れた包み紙ページを撮影して行う。

3. **共通CSS（style.css）に `h1〜h6 { font-family: … !important }` がある。**
   新デザインで明朝体見出しを使う場合、style.css を読み込むと打ち消されてしまう。
   → トップページは style.css を読み込まない独立構成にした。他ページを順次刷新する際も同様に注意。

4. **モックアップ素材には文字が焼き付いていることがある。**
   題名やUI部品が画像に焼き付いている場合、そのまま使うと二重表示になる。
   → 切り抜き＋周辺の背景をぼかして重ねる方法（PIL）で消してから使う。
