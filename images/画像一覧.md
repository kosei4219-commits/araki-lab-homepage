# 画像ファイル一覧

ファイル名は英語ですが、内容は下の表のとおりです。
名前の頭で種類が分かるようにしています。

| 接頭辞 | 意味 |
|---|---|
| `logo-` | ロゴ |
| `hero-` | ページ最上部の大きな背景 |
| `topic-` | 研究テーマの図 |
| `equipment-` | 実験設備の写真 |
| `lab-` | 研究室の様子 |
| `member-` | メンバーの写真 |
